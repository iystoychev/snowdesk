# Security Policy

CokeEverywhere asks for no special permissions. It reads only window positions (never window titles or contents), the cursor position and the Dock's preferences, and it makes no network connections.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's [private vulnerability reporting](https://github.com/iystoychev/coke-everywhere/security/advisories/new) instead. You will get a reply within a few days.

Only the latest release is supported with fixes.
