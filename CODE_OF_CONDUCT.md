# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, and assume good intent. Harassment, insults and personal attacks are not welcome in issues, pull requests or any other project space.

If someone's behavior bothers you, report it privately to the maintainer through the contact options on [@iystoychev](https://github.com/iystoychev)'s GitHub profile. Reports are handled confidentially, and the maintainer may remove content or block people who break these rules.
